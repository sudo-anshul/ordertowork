# README media

These assets illustrate the working OrderToWork application with synthetic businesses, orders, customers, addresses, and receipts. They contain no production customer records. Silent GIF excerpts omit waiting and navigation and do not represent continuous processing speed. The bakery image is a prepared sample.

| Asset | Purpose |
| --- | --- |
| `hero.png` | Product overview using a real workbench capture |
| `01-check-the-change.gif` | Live Strands analysis, tool evidence, and checked alternatives |
| `02-approve-and-produce.gif` | Customer consent, sample deposit, accepted ticket, and production |
| `03-complete-the-handover.gif` | Customer choice, exact delivery quote, and recorded completion |
| Matching numbered PNGs | Static alternatives for readers who prefer reduced motion |
| `bakery.png` | Second configured business profile |
| `architecture.png` / `architecture.pdf` | Deployed system, service boundaries, and fulfillment flow |

GIFs are 1080 × 585, eight frames per second, and contain no audio. They were derived locally from reviewed application recordings. The source film, private capture material, and temporary encoding files are not required to run the app and are not included here.

The architecture uses official AWS architecture icons, the official Qwen3 mark, and original Strands, React, and FastAPI marks. They identify actual components and remain subject to their owners' trademark terms; the repository's MIT license does not grant rights to third-party marks.
